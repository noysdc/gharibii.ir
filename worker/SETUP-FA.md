# نصب Worker فاکتورهای غریبی (Cloudflare)

هزینه: رایگان (پلن Free کلادفلر کافی است). زمان: حدود ۱۵ دقیقه. روی کامپیوتر انجام بده (Node.js لازم است).

## ۱) حساب و ابزار
1. در https://dash.cloudflare.com ثبت‌نام کن (بدون نیاز به انتقال دامنه).
2. در ترمینال، داخل پوشهٔ `worker` ریپو:
   ```
   npm install -g wrangler
   wrangler login
   ```

## ۲) ساخت KV (جای ذخیرهٔ فاکتورها)
```
wrangler kv namespace create INVOICES
```
شناسهٔ چاپ‌شده (`id = "..."`) را در `wrangler.toml` به‌جای `PUT_KV_NAMESPACE_ID_HERE` بگذار.

## ۳) ربات تلگرام (برای اعلان و گزارش)
1. در تلگرام با `@BotFather` چت کن، `/newbot` بزن و اسم بده؛ **توکن** را بگیر.
2. به رباتِ ساخته‌شده یک پیام بده (مثلاً `/start`).
3. این آدرس را در مرورگر باز کن (TOKEN را جایگزین کن) و عدد `"chat":{"id": ...}` را بردار:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`

## ۴) کلیدهای محرمانه
```
wrangler secret put SELLER_KEY            # یک رمز طولانی دلخواه برای صفحهٔ فروشنده
wrangler secret put TELEGRAM_BOT_TOKEN    # توکن مرحلهٔ ۳
wrangler secret put TELEGRAM_CHAT_ID      # عدد مرحلهٔ ۳
```
(اختیاری، ایمیل با resend.com: `RESEND_API_KEY`، `MAIL_TO`، `MAIL_FROM`)

## ۵) انتشار
```
wrangler deploy
```
آدرسی مثل `https://gharibii-invoices.<نام‌تو>.workers.dev` چاپ می‌شود.

## ۶) وصل کردن سایت
در `_config.yml` ریپوی سایت:
```
invoice_api: "https://gharibii-invoices.<نام‌تو>.workers.dev"
```
commit و push کن. بعد از چند دقیقه صفحهٔ `/seller/` را باز کن:
- اولین بار «رمز فروشنده» (همان `SELLER_KEY`) را می‌پرسد.
- پایین صفحه، کارت «سرور، تلگرام و گزارش‌ها» → «تست اتصال» باید پیام آزمایشی را در تلگرام بیاورد.

## چه چیزهایی خودکار می‌شود
- لینک فاکتور: `gharibii.ir/f/050803-1432-k7q2` (سال‌ماه‌روز شمسی - ساعت‌دقیقه - ۴ حرف تصادفی).
- ویرایش فاکتور = همان لینک به‌روز می‌شود. تأیید یا لغو پرداخت هم روی همان لینک اعمال می‌شود.
- تلگرام: فاکتور جدید، اعلام پرداخت توسط مشتری، تأیید پرداخت.
- گزارش هفتگی: هر شنبه ۰۸:۰۰ تهران. گزارش ماهانه: اول هر ماه شمسی. گزارش دستی: دکمه‌های صفحهٔ فروشنده.

## نکته‌ها
- KV «در نهایت سازگار» است: بعد از تأیید پرداخت ممکن است تا حدود یک دقیقه طول بکشد تا مشتری وضعیت تازه را ببیند (صفحه هر ۲۵ ثانیه خودش چک می‌کند).
- اگر `invoice_api` خالی باشد یا سرور در دسترس نباشد، سایت مثل قبل با لینک بلند کار می‌کند.
- هیچ‌وقت `SELLER_KEY` یا توکن‌ها را داخل ریپو ننویس.

# ایمیل (Resend) — فقط برای گزارش‌ها

اعلان‌های لحظه‌ای فقط به تلگرام می‌روند. ایمیل فقط برای **گزارش هفتگی و ماهانه** (و «تست اتصال») استفاده می‌شود.
اگر خواستی اعلان‌ها هم ایمیل شوند: `wrangler secret put MAIL_ALL` و مقدارش را `1` بگذار.

## راه ساده (بدون دامنه) — پیشنهادی
1. در https://resend.com ثبت‌نام کن، **با ایمیلی که می‌خواهی گزارش‌ها به آن برسد**، و ایمیلت را تأیید کن.
2. منوی **API Keys** → «Create API Key» (دسترسی Sending access) → کلید را همان لحظه کپی کن (فقط یک بار نمایش داده می‌شود).
3. در ترمینال (داخل پوشهٔ `worker`):
   ```
   wrangler secret put RESEND_API_KEY     # کلید مرحلهٔ ۲
   wrangler secret put MAIL_TO            # همان ایمیلی که با آن ثبت‌نام کردی
   wrangler secret put MAIL_FROM          # دقیقاً:  Gharibii <onboarding@resend.dev>
   wrangler deploy
   ```
محدودیت: بدون تأیید دامنه، Resend فقط اجازهٔ ارسال به **ایمیل خود حساب** را می‌دهد. برای گزارش‌های خودت همین کافی است.
پلن رایگان: ۳٬۰۰۰ ایمیل در ماه و ۱۰۰ در روز.

## راه حرفه‌ای (ارسال از آدرس خودت، مثل info@gharibii.ir)
در Resend → Domains → Add Domain → `gharibii.ir` و رکوردهای DNS (SPF/DKIM) که نشان می‌دهد را در جایی که DNS دامنه را مدیریت می‌کنی اضافه کن. بعد از تأیید: `MAIL_FROM` = `Gharibii <info@gharibii.ir>` و `MAIL_TO` هر ایمیلی می‌تواند باشد.

# راه‌اندازی گزارش‌های هفتگی و ماهانه

گزارش‌ها خودکار هستند و کار اضافه‌ای لازم ندارند؛ فقط Worker باید دیپلوی شده و `crons` در `wrangler.toml` باشد (هست).

- **هفتگی:** هر شنبه ساعت ۰۸:۰۰ تهران.  **ماهانه:** اول هر ماه شمسی (برای ماه قبل).
- **تست فوری (بدون صبر برای شنبه):** صفحهٔ `/seller/` ← کارت «سرور، تلگرام و گزارش‌ها» ← «گزارش هفتگی» یا «گزارش ماهانه». باید هم در صفحه نمایش داده شود، هم به تلگرام (و ایمیل، اگر وصل کردی) برسد.
- **دیدن زمان‌بندی در کلادفلر:** Workers & Pages ← gharibii-invoices ← Settings ← Triggers ← Cron Triggers باید `30 4 * * *` را نشان دهد.
- **گزارش فقط فاکتورهای «لینک کوتاه» را می‌شمارد** و «پرداخت‌شده» یعنی تأیید پرداخت را در صفحهٔ فروشنده زده باشی.
