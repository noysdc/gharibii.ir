# فروشگاه غریبی کیش

وب‌سایت فروشگاه غریبی کیش با دامنهٔ [gharibii.ir](https://gharibii.ir)؛ کاتالوگ محصولات کودک، دسته‌بندی‌ها، جست‌وجوی محصولات، سبد خرید و ثبت سفارش از طریق واتساپ، به‌همراه ابزار ساخت و مدیریت فاکتور فروشندگان.

## امکانات

### فروشگاه
- طراحی فارسی و راست‌چین و سازگار با موبایل و دسکتاپ
- دسته‌بندی محصولات: پرنسسی دخترانه، شخصیتی پسرانه، کیف و کفش، تاج و عصا و اکسسوری
- صفحهٔ اختصاصی هر محصول با تصاویر، مشخصات، گزینه‌ها، قیمت و وضعیت موجودی
- جست‌وجوی محصولات و نمایش سریع نتایج
- سبد خرید و ساخت متن سفارش برای ارسال در واتساپ و کانال‌های ارتباطی پشتیبانی‌شده
- راهنمای سایز، گالری تصاویر، صفحات اطلاعاتی و اطلاعات تماس

### فاکتور فروشندگان
- ابزار ساخت فاکتور در مسیر `/seller/`
- انتخاب محصول از فهرست همگام‌شده با قیمت‌ها و موجودی سایت
- ثبت مشخصات مشتری، فروشنده، آدرس، کد پستی، هزینهٔ ارسال، تخفیف و روش پرداخت
- تبدیل پیام مشتری به اطلاعات فاکتور
- ساخت، ویرایش و نسخه‌بندی فاکتور و ساخت فاکتور مکمل برای سفارش پرداخت‌شده
- لینک کوتاه فاکتور، نمایش و پرداخت در مسیر `/invoice/`
- نگهداری سابقهٔ محلی فاکتورها و همگام‌سازی وضعیت فاکتورهای مشترک از طریق Cloudflare Worker
- خروجی متن، تصویر و PDF

### اتوماسیون و نگهداری کاتالوگ
- تولید دادهٔ جست‌وجو در `search.json`
- تولید فهرست محصولات و اطلاعات فروشندگان برای ابزار فاکتور در `seller-data.json`
- اسکریپت‌های بررسی، تکمیل اطلاعات، به‌روزرسانی قیمت‌ها و آماده‌سازی تصاویر
- گردش‌کارهای GitHub Actions برای بررسی و به‌روزرسانی داده‌ها و تصاویر

## فناوری‌ها و معماری

- **سایت:** Jekyll و GitHub Pages
- **محتوا:** فایل‌های Markdown در مجموعهٔ `_products`
- **قالب‌ها و اجزای مشترک:** Liquid، پوشه‌های `_layouts` و `_includes`
- **ظاهر و رفتار سمت کاربر:** CSS و JavaScript بدون چارچوب فرانت‌اند
- **فاکتورها و لینک‌های کوتاه:** Cloudflare Worker و فضای ذخیره‌سازی KV
- **تصاویر:** فایل‌های WebP و تصاویر بندانگشتی
- **دامنه و انتشار:** دامنهٔ اختصاصی `gharibii.ir` و GitHub Pages

## ساختار مخزن

| مسیر | کاربرد |
|---|---|
| `_products/` | اطلاعات محصولات در فایل‌های Markdown |
| `_data/` | داده‌های تنظیمات و گروه‌های قیمت |
| `_includes/` | اجزای مشترک قالب |
| `_layouts/` | قالب صفحات محصول، ابزار و صفحات عادی |
| `assets/css/` | استایل‌های سایت و فاکتور |
| `assets/js/main.js` | رفتار عمومی سایت، جست‌وجو و سبد خرید |
| `assets/js/seller.js` | ابزار فروشنده، انتخاب محصول و سابقهٔ فاکتورها |
| `assets/js/invoice.js` | منطق مشترک فاکتورها، داده‌ها و ارتباط با Worker |
| `assets/js/invoice-view.js` | نمایش فاکتور برای مشتری |
| `search.json` | نمایهٔ جست‌وجوی محصولات |
| `seller-data.json` | دادهٔ محصولات، قیمت‌ها، موجودی و فروشندگان برای ابزار فاکتور |
| `seller.html` | صفحهٔ ساخت فاکتور فروشنده |
| `invoice.html` | صفحهٔ مشاهده و پرداخت فاکتور |
| `worker/src/index.js` | API فاکتورها و اعلان‌ها |
| `scripts/` | ابزارهای بررسی، به‌روزرسانی و آماده‌سازی داده‌ها |
| `.github/workflows/` | گردش‌کارهای خودکار GitHub Actions |

## راه‌اندازی محلی

پیش‌نیازها: Ruby، RubyGems و Bundler.

```bash
bundle install
bundle exec jekyll serve
```

سپس سایت محلی را در نشانی `http://localhost:4000` باز کنید.

برای ساخت خروجی نهایی:

```bash
bundle exec jekyll build
```

## افزودن یا ویرایش محصول

1. فایل Markdown محصول را در پوشهٔ دسته‌بندی مناسب داخل `_products/` ایجاد یا ویرایش کنید.
2. عنوان، توضیحات، تصاویر، گزینه‌ها، شناسهٔ گروه قیمت و وضعیت موجودی را در فرانت‌متر همان فایل تنظیم کنید.
3. تصاویر را در مسیر متناظر داخل `assets/images/products/` قرار دهید و مسیر آن‌ها را در اطلاعات محصول وارد کنید.
4. گروه‌های قیمت در صورت نیاز از `_data/price_groups.yml` مدیریت می‌شوند.
5. پس از ساخت سایت، خروجی‌های `search.json` و `seller-data.json` از روی اطلاعات محصولات تولید می‌شوند؛ آن‌ها را به‌عنوان منبع مستقل و دستی ویرایش نکنید.

## تنظیمات و اطلاعات محرمانه

تنظیمات عمومی سایت در `_config.yml` قرار دارد؛ از جمله اطلاعات تماس، فروشندگان، روش‌های سفارش، هزینهٔ ارسال و تنظیمات نمایش پرداخت.

مقادیر محرمانه را در مخزن عمومی قرار ندهید. کلید فروشنده، توکن ربات تلگرام، شناسهٔ پذیرندهٔ درگاه و سایر مقادیر خصوصی باید در بخش Secrets/Bindings سرویس مربوطه (مانند Cloudflare Worker) تنظیم شوند، نه در فایل‌های عمومی مخزن.

آدرس Worker فاکتورها از گزینهٔ `invoice_api` در `_config.yml` خوانده می‌شود. تغییر کد Worker به‌تنهایی کافی نیست؛ در صورت تغییر آن باید نسخهٔ جدید Worker نیز در Cloudflare منتشر شود.

## جست‌وجو

دو نمایهٔ جست‌وجو وجود دارد:

- جست‌وجوی عمومی سایت: `search.json` توسط Jekyll ساخته می‌شود و `assets/js/main.js` آن را می‌خواند.
- جست‌وجوی انتخاب محصول در فاکتور: داده‌های `seller-data.json` را در `assets/js/seller.js` جست‌وجو می‌کند.

هر دو بخش باید یکسان‌سازی حروف فارسی و عربی، ارقام فارسی و عربی، نیم‌فاصله و فاصله را رعایت کنند. پس از تغییر قالب داده یا منطق جست‌وجو، خروجی سایت را دوباره بسازید و هر دو مسیر را جداگانه آزمایش کنید.

## اسکریپت‌ها و گردش‌کارها

اسکریپت‌های پوشهٔ `scripts/` برای کارهای کاتالوگ، تصاویر، قیمت‌ها و کانال تلگرام هستند. راهنمای همان پوشه و فایل‌های گردش‌کار در `.github/workflows/` را پیش از اجرای دستی یا تغییر زمان‌بندی بررسی کنید.
